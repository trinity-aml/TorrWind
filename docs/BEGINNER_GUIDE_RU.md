# TorrWind: гид для новичков

Этот гид описывает обычную установку, первичную настройку и базовое использование TorrWind на Windows 10/11 x64.

## Что такое TorrWind

TorrWind - desktop-приложение для управления TorrServer. Оно может работать двумя способами:

- `Локальный TorrServer`: TorrWind сам скачивает, запускает и настраивает TorrServer на этом же компьютере.
- `Удаленный TorrServer`: TorrWind подключается к уже работающему TorrServer по IP-адресу или домену.

Для первого запуска проще выбрать локальный режим.

## Что скачать

На странице релиза обычно есть два варианта:

- `portable zip`: распаковывается в любую папку и запускается без установки.
- `installer exe`: устанавливает TorrWind через обычный установщик Windows.

Для новичка удобнее `portable zip`: вся рабочая папка, настройки, логи, плейлисты, TorrServer и кеш будут лежать рядом с `TorrWind.exe` в папке `Data`.

## Установка portable-версии

1. Скачайте `TorrWind-...-win-x64-portable.zip`.
2. Распакуйте архив в постоянную папку, например:

   ```text
   D:\Apps\TorrWind
   ```

3. Запустите `TorrWind.exe`.
4. Если Windows SmartScreen показывает предупреждение, проверьте, что файл скачан из вашего релиза TorrWind, и нажмите `Подробнее -> Выполнить в любом случае`.

Не запускайте portable-версию прямо из архива. Сначала распакуйте ее в папку.

## Первичная настройка локального TorrServer

1. Откройте `Настройки -> TorrServer`.
2. Нажмите `Проверить latest` или `Загрузить релизы`.
3. Нажмите `Скачать TorrServer`.
4. После скачивания нажмите `Сохранить`.
5. Нажмите `Запустить локально`.
6. Откройте `Диагностика -> Диагностика` и нажмите `Запустить диагностику`.
7. Убедитесь, что выбранный сервер доступен.

После этого TorrWind готов добавлять торренты и запускать воспроизведение.

## Локальный сервер как служба Windows

Служба нужна, если TorrServer должен работать без открытого окна TorrWind или стартовать вместе с Windows.

1. Откройте `Настройки -> Сервис`.
2. Включите запуск локального сервера как службы, если такой переключатель доступен.
3. Нажмите `Сохранить`.
4. Нажмите `Установить службу`.
5. Подтвердите повышение прав Windows.
6. Нажмите `Запустить службу`.
7. Проверьте состояние кнопкой `Статус службы`.

Повышение прав требуется только для установки, удаления, запуска и остановки службы. Обычная работа TorrWind не требует прав администратора.

Если вы используете службу, не запускайте тот же TorrServer вторым процессом на том же порту.

## Подключение к удаленному TorrServer

Если TorrServer уже работает на другом устройстве:

1. Откройте `Настройки -> Серверы`.
2. Нажмите `Добавить сервер`.
3. Укажите имя, например `Home server`.
4. Укажите URL:

   ```text
   http://192.168.1.2:8090
   ```

5. Если на сервере включена авторизация, заполните логин и пароль.
6. Если сервер использует самоподписанный HTTPS-сертификат, можно включить `Игнорировать ошибки сертификата`.
7. Нажмите `Сохранить`.
8. Нажмите `Проверить подключение`.

Удаленный сервер можно использовать для библиотеки, поиска, Web UI и воспроизведения так же, как локальный.

## Базовые настройки TorrServer

Откройте `Настройки -> TorrServer`.

Минимальный набор для начала:

- `Кэш`: оставьте `Memory`.
- `Размер кеша`: для начала достаточно `64`.
- `Предзагрузка %`: можно оставить `50`.
- `Опережающий кэш %`: можно оставить `95`.
- `Таймаут отключения`: можно оставить `30`.
- `Соединения`: можно оставить `25`.

Если памяти мало или вы хотите хранить кеш на диске, переключите кеш в `Disk` и укажите папку кеша. Для portable-режима удобно использовать папку внутри `Data\TorrServer\cache`.

После изменения runtime-настроек нажмите:

1. `Сохранить`, чтобы сохранить настройки TorrWind.
2. `Применить runtime настройки`, чтобы отправить их в текущий TorrServer.

## TMDB и постеры

TMDB нужен для поиска постеров и метаданных.

1. Получите TMDB API key в аккаунте TMDB.
2. Откройте `Настройки -> TorrServer`.
3. В блоке `TMDB` заполните:

   ```text
   API-ключ
   API URL
   URL изображений
   URL изображений RU
   ```

4. Обычно можно оставить URL по умолчанию:

   ```text
   https://api.themoviedb.org
   https://image.tmdb.org
   https://imagetmdb.com
   ```

5. Нажмите `Сохранить`.
6. Нажмите `Применить runtime настройки`.

API-ключ хранится в настройках TorrWind. При создании архива поддержки ключ не должен попадать в отчет в открытом виде.

## Добавление торрента

Откройте `Библиотека`.

Можно добавить:

- `.torrent` файл через `Добавить .torrent`;
- magnet-ссылку через `Добавить magnet`;
- результат поиска из вкладки `Поиск`.

После добавления TorrWind обновляет информацию по торренту. Если данные не появились сразу, нажмите `Обновить` или `Обновить выбранный`.

## Просмотр фильмов и сериалов

1. Откройте `Библиотека`.
2. Выберите торрент слева.
3. Ниже выберите файл или серию.
4. Нажмите `Открыть плеер`.

По умолчанию используется встроенный mpv-плеер.

Для сериалов доступны:

- выбор серии из плейлиста;
- переход к предыдущей или следующей серии;
- `Продолжить`, чтобы открыть просмотр с последней позиции;
- `Плейлист с выбранной`, чтобы сформировать плейлист от выбранной серии до последней.

В плеере доступны настройки аудио, видео и субтитров:

- выбор аудиодорожки;
- выбор видеодорожки;
- выбор субтитров;
- задержка аудио;
- задержка субтитров;
- соотношение сторон.

## Внешний плеер

Если вы хотите использовать VLC, MPC-HC, PotPlayer или другой плеер:

1. Откройте `Настройки -> Сервис`.
2. Найдите настройки плеера.
3. Выберите нужный тип плеера.
4. Для пользовательского плеера укажите путь к `.exe`.
5. Нажмите `Сохранить`.

Если внешний плеер не открывает ссылку, проверьте, умеет ли он работать с HTTP stream/M3U-ссылками TorrServer.

## Поиск

TorrWind умеет искать двумя способами:

- через выбранный TorrServer, если поиск настроен в самом TorrServer;
- напрямую через Torznab-совместимые индексеры, например Jackett, Prowlarr или JacPro.

### Поиск через TorrServer

1. Откройте `Поиск`.
2. Выберите режим `Выбранный TorrServer`.
3. Введите запрос.
4. Нажмите `Поиск`.

Если в Web UI TorrServer поиск работает, но в TorrWind нет, проверьте выбранный сервер, логин/пароль и диагностику.

### Добавление индексера

1. Откройте `Настройки -> Индексеры`.
2. Нажмите `Добавить провайдер`.
3. Укажите имя индексера.
4. Укажите URL Torznab/JacPro/Prowlarr/Jackett.
5. Если нужен API key, заполните его.
6. При необходимости заполните категории.
7. Нажмите `Сохранить`.

Примеры URL:

```text
http://127.0.0.1:9117/api/v2.0/indexers/all/results/torznab
http://192.168.1.2:9696/api/v1/indexer/all/results/torznab
http://192.168.1.2:5002
```

После этого откройте `Поиск` и выберите поиск по провайдерам.

## Web UI

Вкладка `Web UI` открывает встроенный web-интерфейс TorrServer. Она полезна, если нужная функция еще не вынесена в native-интерфейс TorrWind.

Если Web UI показывает ошибку сценария:

1. Проверьте, что выбран правильный сервер.
2. Откройте Web UI в обычном браузере по тому же адресу.
3. Проверьте, что TorrServer обновлен.
4. Посмотрите `Диагностика -> Журнал`.

## Tray и закрытие программы

TorrWind работает как tray-приложение возле часов.

- Кнопка закрытия окна может свернуть приложение в tray.
- Кнопка `Выход` полностью закрывает GUI.
- Если локальный TorrServer запущен как служба, он может продолжить работать после закрытия GUI.
- Если локальный TorrServer запущен как дочерний процесс GUI, он зависит от режима запуска и настроек приложения.

## Резервные копии настроек

Настройки хранятся в рабочей папке:

```text
Data\settings.json
```

В настройках доступны:

- экспорт настроек;
- импорт настроек;
- восстановление backup;
- настройка количества backup-файлов.

Перед экспериментами с серверами, индексерами и runtime JSON полезно сделать экспорт настроек.

## Диагностика и журналы

Если что-то не работает:

1. Откройте `Диагностика -> Диагностика`.
2. Нажмите `Запустить диагностику`.
3. Нажмите `Сохранить отчет` или `Архив поддержки`.
4. Откройте `Диагностика -> Журнал` и проверьте последние ошибки.

Основные журналы:

```text
Data\logs\gui.jsonl
Data\logs\service.jsonl
Data\logs\mpv-player.log
```

Архив поддержки очищает чувствительные значения в настройках, но перед отправкой отчета все равно полезно просмотреть его самостоятельно.

## Частые проблемы

### TorrServer не запускается

- Проверьте, что файл TorrServer скачан.
- Проверьте, что порт `8090` не занят другим процессом.
- Если включена служба, не запускайте второй локальный процесс на том же порту.
- Откройте `Диагностика -> Журнал`.

### Не работает удаленный сервер

- Проверьте URL в браузере.
- Проверьте логин и пароль.
- Для HTTPS с самоподписанным сертификатом включите `Игнорировать ошибки сертификата`.
- Проверьте firewall на устройстве, где запущен TorrServer.

### Не работает поиск

- Проверьте, работает ли поиск в Web UI TorrServer.
- Для внешних индексеров проверьте URL и API key.
- Увеличьте timeout индексера.
- Проверьте, что выбран правильный режим поиска.

### Плеер не открывает видео

- Проверьте, что torrent получил информацию о файлах.
- Попробуйте `Обновить выбранный`.
- Попробуйте открыть тот же URL во внешнем VLC/mpv.
- Проверьте `Data\logs\mpv-player.log`.

### Нет аудиодорожек или субтитров

- Подождите несколько секунд после начала воспроизведения.
- Откройте настройки дорожек в плеере.
- Проверьте, есть ли дорожки в самом файле.

### Служба не устанавливается или не запускается

- Устанавливайте службу через кнопку в TorrWind, подтвердив права администратора.
- Проверьте путь к `TorrServer.exe`.
- Проверьте `Data\logs\service.jsonl`.
- Если меняли настройки, нажмите `Сохранить` перед запуском службы.

## Безопасные привычки

- Держите portable-папку TorrWind в месте, где у пользователя есть права записи.
- Не храните TorrWind в `Program Files`, если используете portable-режим без прав администратора.
- Не публикуйте свои API keys, пароли и magnet-ссылки в открытом виде.
- Перед обновлениями и ручным редактированием JSON делайте backup настроек.
- Для первого запуска используйте простую схему: локальный TorrServer, memory cache 64 МБ, встроенный mpv.
